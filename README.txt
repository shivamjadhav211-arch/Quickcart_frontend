QUICKCART - COMPLETE PROJECT CODE PACK

Files:
- index.html / index1.html: Home
- products.html: 20 products, search and category filters
- cart.html: Cart quantities, removal and totals
- checkout.html: Delivery form, totals, POST /api/orders and confirmation redirect
- order-success.html: Order confirmation and ID
- login.html / signup.html: Backend-connected account pages
- style.css: Shared styling
- script.js: Cart, search, filters, login/signup helpers
- backend/server.js: Express API
- backend/users.json / backend/orders.json: JSON storage

SETUP:
1. Open the QuickCart_All_Code folder in VS Code.
2. Open a terminal in the backend folder.
3. Run: npm install
4. Run: npm start
5. Keep the backend terminal open.
6. Open the root folder in VS Code and use Live Server on index1.html.
7. Add products, open cart, proceed to checkout, and submit an order once.
8. Backend test: http://localhost:3000/api/test
9. Orders list: http://localhost:3000/api/orders
